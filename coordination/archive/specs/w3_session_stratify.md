= W3 — **세션을 1급 차원으로** 넣고 전부 다시 갈라라 (사용자 지적, 오염 가능성 높음)

## 사용자 지적 (2026-08-03)

> "지금 데이터가 정규장 이전 데이터인지 확인하고, 정규장 이전이면 그것도 **반드시 판단에 포함**.
> 정규장이 아닌 거래 데이터에서는 **거래량과 유동성이 현저히 낮다.**"

**옳은 지적이고, 코디네이터가 확인해 보니 심각하다.**

> **주의 — 이 표를 그대로 믿지 마라.** 티어2 승격이 동적이라 **세션마다 종목 구성이 다르다.**

> **"세션을 나눠 제대로 재야 한다"의 증거**다. 그게 네 일이다.

## 작업

### 1. 세션을 **1급 차원**으로 넣어라
`design_b.py`·`exit_value.py` 의 모든 표에 **세션 열**을 추가하라.
KST 기준 경계: day 09:00–17:00 / pre 17:00–22:30 / **REGULAR 22:30–05:00** / after 05:00–08:50.
- 세션 판정 함수는 **한 곳에** 두고 양쪽이 공유하라(중복 정의 금지).
- 세션 경계에 걸친 진입은 **진입 시각 기준**으로 배정하고 그 규칙을 문서에 적어라.

### 2. 기존 결과를 **세션별로 다시 내라**
185 진입이 세션별로 몇 건인지, 총수익·위약 대비 차이·상한이 세션별로 어떻게 다른지.
- **정규장 표본이 몇 건인지 반드시 세어라.** 부족하면 "판정 불가 + 필요 일수"로.
- 판정이 세션에 따라 갈리면 **결론을 세션별로 다시 써라.**

### 3. **세션별 비용 모델** (제일 값어치 있다)
지금 `CLIP_COSTS` 는 세션 구분 없는 단일 값이다. 세션별로 다시 재라.
- **종목 구성을 맞춰라** — 같은 종목이 여러 세션에 걸쳐 호가 데이터를 가진 경우만 비교하는
  **종목 내 대조**가 가장 깨끗하다. 못 맞추면 못 맞춘다고 적고 표본 수를 밝혀라.
- 산출: 세션 × 클립($100/500/1000/2000) 비용표.
- **이것이 전략 생사에 직결된다.** 지금 결론("총수익 0.5% < 비용 2.38%")이
  **세션 혼합의 산물**일 수 있다.

### 4. 판정
세션을 가른 뒤 **결론이 바뀌는가**를 명시적으로 적어라. 안 바뀌면 안 바뀐다고 적어라.
**억지로 뒤집지 마라** — 지금까지 네 번 죽인 규율이 이번에도 적용된다.
