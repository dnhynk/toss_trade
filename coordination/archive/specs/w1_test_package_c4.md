= 감사4 C4 — tests 패키지화와 형제 import 정리 (W1)

너는 W1(`tossmon/api/**`, `tools/live_probe.py`, `tools/mock_server.py`, `tests/fixtures/**`,
`docs/06_live_facts.md` 소유자)다. 감사 4차의 C4 항목이 **아직 미해결**이고, W3 가
시도했다가 되돌렸다. 관련 파일이 대부분 네 소유라 너에게 배분한다.

## 문제

감사는 `tests/__init__.py` 추가를 권고했으나, **그 한 줄만 넣으면 이 리포가 깨진다** —
`tests` 가 패키지가 되는 순간 형제 모듈의 bare import(예: `import synth`)가 전부 실패해
**5개 모듈에서 수집 에러, 스위트 사망**. W3 가 재현하고 되돌렸다(그 판단은 옳다).

제대로 고치려면 **`__init__.py` 추가 + 형제 import 일괄 정리**를 **한 커밋**에 해야 한다.

## 작업

1. 현재 `tests/` 의 형제 import 를 전수 조사하라(bare import 로 같은 디렉터리 모듈을
   가져오는 곳 전부).
2. 패키지화가 **정말 이득인지 먼저 판단하라.** 감사의 근거를 확인하고,
   - 이득이 비용보다 크면: `__init__.py` + 상대/절대 import 정리를 한 커밋으로.
   - 아니면: **고치지 말고** 왜 현 구조가 낫다고 보는지 근거와 함께 (c)에 적어라.
   감사 지적이라고 무조건 따르지 마라 — W3 가 이미 "한 줄 수정은 명백히 해롭다"를 보였다.
3. 어느 쪽이든 **전체 pytest 가 지금과 같거나 더 나은 상태**여야 한다(현재 1003 passed).

## 불변 규칙

라이브 호출 금지(mock 전용), `api_keys` 금지, W5 수집 DB 접근 금지(수집 가동 중),
소유 경로 밖 수정은 이 태스크 한정으로 `tests/` 하위 import 정리에 필요한 만큼만 허용하되
**변경 파일 목록을 (a)에 전부 명시**하라. `feat/core-api` 커밋, main 금지,
`worker_done` 1회(ASCII), (a)~(e).
