# W2 — 유니버스 빌드 실패 수정 (심볼 문자셋)

너는 W2(`tossmon/store/**`, `tossmon/universe/**`, `tests/test_store*.py`,
`tests/test_universe*.py` 소유자)다. **오케스트레이션이 리셋됐다** — 옛 ID 는 무효다.
네 재개 지점은 `coordination/HANDOFF-W2.md` 에 있다.

**라이브 호출 금지** (`TOSS_LIVE=0`, `TOSS_BASE_URL=http://127.0.0.1:8899`).
지금 W5 가 라이브 리스를 갖고 재수집을 시도 중이다 — 네가 토큰을 발급하면 그게 죽는다.

## 실패 (라이브에서 실제로 터졌다)
W5 가 `python -m tossmon.universe` 를 돌렸고 **첫 배치에서 즉시 죽었다**:
```
2026-07-31 13:30:57 ERROR universe build failed
  build.py:38  metas.extend(await client.get_stocks(chunk))
  client.py:369  raise SchemaMismatch(f"http-{status} ...")
tossmon.api.errors.SchemaMismatch: http-400 code=invalid-request
                                   message=요청 필드가 올바르지 않습니다
```

## 원인 (코디네이터가 확정했다 — 추측 아님)
`seed.py:18` 의 심볼 정규식이 **`$` 를 허용한다**:
```python
_SYMBOL_RE = re.compile(r"^[A-Z0-9][A-Z0-9.$-]*$")
```
그런데 **토스 API 는 `$` 를 허용하지 않는다.** 스펙 문구(`docs/01_api_analysis.md` §3.1):
> 영문 대/소문자, 숫자, `'.'`, `'-'` 만 허용한다.

NASDAQ 디렉토리는 **우선주를 `ABR$D` 형식**으로 표기한다. 실측:
- 파싱된 심볼 **7,478개 중 387개**가 `$` 를 포함한다.
- **첫 200개 배치에만 7개**가 들어 있다(`ABR$D ABR$E ABR$F ACP$A ACR$C ACR$D ADC$A`).
- 배치 중 하나라도 불량이면 **배치 전체가 400** 이라 유니버스 빌드가 첫 콜에서 죽는다.

## 수정
1. `seed.py` 의 심볼 정규식에서 **`$` 를 제거**하라 — 토스 API 문자셋(`[A-Za-z0-9.\-]`)과 맞춘다.
   `$` 심볼은 우선주이고, 우리 유니버스는 `is_common=True`(보통주)만 보므로
   **애초에 걸러져야 할 대상**이다. 즉 필터를 느슨하게 하는 게 아니라 **정확하게** 만드는 것이다.
2. **거른 심볼 수를 로그로 남겨라.** 조용히 387개를 버리면 나중에 "왜 이 종목이 없지"를 추적 못 한다.
3. **방어를 한 겹 더**: `build.py` 가 `get_stocks` 에 넘기기 전에 문자셋을 검증하고,
   불량 심볼은 제외 + 카운트하라. 디렉토리 포맷이 바뀌어도 배치 전체가 죽지 않아야 한다.
   지금 구조는 **불량 1개가 배치 200개를 전부 날린다** — 그게 이번 실패의 본질이다.
4. **더 나은 실패 처리**: 배치가 400 으로 죽으면 유니버스 빌드 전체가 중단된다.
   배치 단위로 실패를 격리해(해당 배치만 스킵 + 경고) 나머지는 진행되게 할지 판단하라.
   단 **조용한 스킵은 금지** — 스킵 건수와 사유가 요약에 나와야 한다.

## 테스트
- `$` 포함 심볼이 파싱 단계에서 **제외되는지** (`ABR$D` 등 실제 사례로)
- 거른 수가 로그/요약에 드러나는지
- 불량 심볼이 섞인 배치에서 `build_universe` 가 **전체 중단되지 않는지**
- 기존 정상 심볼은 그대로 통과하는지 (회귀)

## 불변 규칙
1. 라이브 호출 금지, `api_keys` 읽기 금지.
2. 소유 경로 밖 수정 금지. 완료 시 `git diff --name-only $(git merge-base main HEAD)..HEAD` 로 증명.
3. `main` 직접 커밋 금지. 보고 전 `git log` 확인.
4. **속도가 중요하다** — W5 의 재수집이 이것 때문에 막혀 있다. 작은 수정이니 빠르게 처리하라.
5. `worker_done` 정확히 1회, 보고 (a)~(e).
