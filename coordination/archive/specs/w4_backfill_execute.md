# W4 — 백필 라이브 실행 (사전 점검 → 스크린 → 추정 → 보고 후 정지, go 는 코디네이터가)

너는 W4 다. 네가 만든 `tools/backfill.py` 를 **라이브로 실행**한다. 코디네이터가 감사
보고·사용자 지시 절차를 마쳤고, W5 수집은 종료·리스 해제됐다(코디네이터가 STOP 처리).
**이 태스크는 라이브 호출을 허가한다** — 단 아래 순서와 정지선 안에서만.

## 실행 순서 (w4-collector 워크트리, `git rebase main` 먼저 — main = 63ac979, 826 passed)

0. **환경**: `TOSS_LIVE=1`, `TOSS_BASE_URL=https://openapi.tossinvest.com` 명시
   (env 누락이 어제 2시간 사고의 원인이었다 — tokens.py 가 읽는 env 전부 확인).
   저장 DB 는 **`data/backfill.db` (수집 DB 와 분리)**. 리스는 실행하면 자동 취득 —
   "token lease already held" 가 나오면 즉시 escalation (수집기 잔존 의미).
1. **사전 점검 1콜**: `/market-calendar/US` 로 **2025-10-06 (추석 연휴 중 미국장 개장일)**
   조회 — `dayMarket` 노드가 None/부재인지 실측해 보고에 명시 (감사 F-1 의 전제 확인).
   None 이 아니면 그것대로 보고 (F-1 수정은 어느 쪽이든 유효하다 — 사실 확인용).
2. **유니버스 빌드**: `python -m tossmon.universe` 를 backfill DB 에 — symbols 채움
   (E2E 리허설 발견: 백필은 symbols 를 안 채우므로 이게 선행돼야 §2.7 필터가 산다).
3. **캘린더 캡처**: 분석 대상 전 구간(종목별 가용 시작 ~ 2026-07-31)의 캘린더를 API 로
   걷어 W3 의 `save_calendar` 형식으로 저장 (리허설 발견: 영속화 없이는 분석이
   오프라인으로 못 돈다). 백필 러너의 달력 걷기와 중복되면 캐시 공유로 아껴라.
4. **스크린**: `--screen-only` (15~45분 예상).
5. **추정**: `--estimate` (호출 0회) — 1분봉 본실행의 정확한 호출수·소요 시간.
6. **정지선**: 여기서 멈추고 `status` 로 보고하라 — 스크린 후보 수, 예상 호출량·시간,
   `dayMarket` 실측 결과, 유니버스/캘린더 요약. **본실행(1분봉 백필)은 코디네이터의
   GO 를 받은 뒤에만** 시작한다. GO 후 본실행 → 완료 시 매니페스트 요약과 함께
   `worker_done` (본문 ASCII).
