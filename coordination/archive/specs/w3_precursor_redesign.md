# W3 — 전조 측정식 재설계 (회전 인지형) — 사용자 직접 지시

너는 W3 다. 사용자 지시: **전조 탐지를 사이드로 강등했다고 방치하지 말고, 메인 논제와
결합해 재설계하라.** 메인 논제(docs/16): 개미 유동성이 그날의 러너들 사이를 **계속
옮겨다닌다**. 따라서 물어야 할 질문은 바뀐다:

> (구) "이 종목이 곧 급등할까?" — 단일 종목 예측. 개인 스크립트로 사실상 불가.
> **(신) "유동성이 지금 어느 종목으로 옮겨가고 있는가?" — 러너 집합 안에서의 회전 감지.**

후자는 우리에게 유리하다: 상대 비교라 절대 예측보다 쉽고, 우리가 이미 그 데이터를
갖고 있다(랭킹 스냅 ~12초, 1분봉, 호가 1레벨, 체결 표본).

## 1. 실패 원인 정본화 (같은 실수 반복 금지)

`vol_surge_lead_min`(얼린 측정식)이 왜 무의미했는지 docs 에 명시하고, 새 설계의
**금지 규칙**으로 삼아라:
- **무체결 분을 0 거래량으로 채워 베이스라인 분산을 계산** → 희소 테이프에서 분산이
  0 에 수렴 → 아무 체결이나 z≥3 발화. 실측: 충전율 분위별 검출률 0.876/0.542/0.487/0.280
  (= 검출률이 **데이터 밀도의 역지표**). 51%가 창 가장자리(55~60분)에서 발화.
- 교훈 3가지를 새 설계에 강제: ① **결측을 값으로 채우지 말 것**(결측은 결측으로),
  ② 시계(clock-time) 대신 **사건 시간(체결·프린트 발생 순서)** 기반 통계 고려,
  ③ 창 가장자리 집중은 "측정 창이 신호보다 짧다"는 신호 — 창 의존성을 반드시 진단.

## 2. 새 측정식 설계 요건

**핵심**: 전조 = "이 종목으로 유동성이 회전해 들어오는 중" 의 관측 가능한 흔적.
후보 축(네가 데이터로 선별하되, 최소 이것들은 검토):
- **횡단면(cross-sectional)**: 그날의 러너 후보군 안에서의 상대 순위 변화 —
  거래대금·프린트 빈도·스프레드 축소가 **동시에 다른 종목들 대비** 튀는가.
- **회전 이벤트 자체**: 랭킹 상위권의 구성 변화(A 이탈 ↔ B 진입)와 그 시차 —
  실시간 수집 구간에서만 가능. **이것이 메인 논제의 직접 측정이다.**
- **테이프 미세구조**: 프린트 간격(체결 빈도 급변), 프린트당 크기 변화,
  `first_print`(휴면 각성) — 희소 데이터에서도 정의되는 통계로.
- **호가**: 1레벨 스프레드 축소·잔량 변화 (수집 중, 백필엔 없음 — 실시간 전용 축).

**필수 설계 조건**:
1. 희소 테이프에서 **정의되지 않으면 NaN 을 반환**하고 그 사실을 카운트할 것.
   "값이 나온 것"과 "신호가 있는 것"을 구분 가능하게.
2. **검출률이 데이터 밀도와 무상관**임을 증명할 것 — 충전율 분위별 검출률을 보고하고,
   구 측정식의 0.876→0.280 같은 단조 패턴이 없어야 한다. **이 검증을 통과 못 하면
   그 측정식은 폐기**하고 다시 설계하라.
3. **음성 대조군(negative control)**: 이벤트가 없던 (심볼, 매매일)에서 같은 측정식이
   얼마나 발화하는지 — 정밀도를 계산할 수 있어야 한다. 대조군 규약은 §3 의 Q1 대조군
   정의를 재사용.
4. **창 의존성 진단**: 리드타임 분포가 측정 창 가장자리에 쏠리면 창을 넓혀 재측정.

## 3. 성격·규율 (중요)

- 이것은 **측정 도구 개발**이지 가설 검정이 아니다. **§4.5 2단계 조건부 규칙 탐색과
  구분**하고, 검증 깔때기 5칸을 소모하지 않는다(훈련 구간 + 실시간 구간 기술통계만).
  docs/13 에 exploratory 로 등록.
- **홀드아웃 열람 절대 금지** (상한 2026-04-30 유지).
- 새 측정식이 사전등록의 얼린 정의(`vol_surge_lead_min`)를 **대체**하려면 §9 개정이
  필요하다 — 네가 개정하지 말고, 설계·검증 결과를 근거로 **개정 제안서**를 리포트에
  담아라(코디네이터·W7 이 처리).
- 백필 데이터엔 랭킹·호가가 없다 → 횡단면·회전 축은 **실시간 수집분 전용**이고 지금은
  1일치뿐이다. 그러므로 이번 태스크의 산출은 **"측정식 + 검증 방법론 + 1일치 파일럿"**
  이고, 본 검증은 수집일이 쌓인 뒤다. 그 점을 리포트에 명시하고, **수집이 쌓일수록
  자동으로 재실행 가능한 형태**로 코드를 남겨라.
