## 1. **위약 대비 차이의 CI** (이게 제일 중요하다 — 없으면 주장할 수 없다)

지금 `real_minus_placebo` 는 **점추정치만** 있다(+0.39 ~ +0.61pp, 2건은 음수).
그런데 실제 gross 자체의 CI 가 **12규칙 전부 0 을 교차**한다
(`downtick_1` [-0.16%, +1.28%]). 그러므로 **"과매도 규칙에 +0.55pp 엣지가 있다"는
현재 데이터로 주장할 수 없다.** 차이에 부트스트랩 CI 를 붙여라.

- 실제·위약을 **같은 진입 시각 집합**에서 뽑았으므로 **쌍체(paired) 부트스트랩**이 맞다.
  씨앗별 위약을 평균낸 뒤 진입 단위로 재표집하라(씨앗을 독립 표본으로 세지 마라 —
  씨앗은 5개뿐이고 같은 데이터를 공유한다).
- 결과를 세 갈래로 명확히 적어라: **0 초과 / 0 교차 / 0 미만.**
- 규칙 12개를 다 보면 다중검정이다. **본페로니 등으로 보정한 값도 병기**하라.

## 2. **지정가 비용 모델로 다시 한 번** (판정이 달라질 수 있다)

현재 헤드라인 2.38% 는 `docs/21` 의 **호가창을 가로지르는(시장가성)** 실측이다.
그런데 사용자 전제는 처음부터 **SOR + 지정가**다. 확정된 사실:

> **`docs/06` §7: 미국 주식 수수료 0.1%/편도 = 왕복 0.2%** (외부 확인 완료, 계약 A2 §5)

즉 **지정가가 스프레드를 가로지르지 않고 체결되면 왕복 비용은 0.2% + 잔여 항목**이다.
최고 gross 점추정치 **+0.5%** 는 **0.2% 는 넘고 2.38% 는 한참 못 넘는다.**
**전략의 생사가 이 한 칸 사이에 있다.**

- 비용 시나리오를 **3종 병기**하라: (i) 시장가 2.38%(현행), (ii) **지정가 0.2%(수수료만)**,
  (iii) 절충(한쪽 다리만 지정가 = 0.2% + 편도 스프레드).
- **(ii)는 상한 시나리오임을 명시**하라 — 미체결·역선택을 0으로 가정한 낙관치다.
  실제 체결 품질은 **측정된 적이 없다**(D-2). 이 표를 "지정가면 된다"로 읽히게 쓰지 마라.
- `target_Npct` 의 체결률(0.714/0.595/0.470)이 이미 지정가 미체결의 대가를 보여준다 —
  중앙값은 목표가 그대로인데 평균이 0 근처인 것이 그 증거다. **함께 해설하라.**
