# W4 수정 — 유니버스 미적용 + 룩어헤드/중복 (감사 최상위 blocker 2건)

너는 W4(`tossmon/collector/**`, `tossmon/config.py`, `tests/test_collector*.py` 소유자)다.
적대적 감사 2건이 **네 영역에서 최상위 결함 2건**을 찾았다. 둘 다 **Phase 2 착수 blocker** 다.

**라이브 리스 없음 — 실서버 호출 절대 금지** (W5 가 야간 수집 중이고, 토큰 결함 때문에
네가 발급하면 그 수집이 즉사한다). mock 전용: `TOSS_LIVE=0`, `TOSS_BASE_URL=http://127.0.0.1:8899`.
**W5 의 라이브 DB(`w5-ops/data/tossmon.db`)를 절대 건드리지 마라.**

## 읽을 것
`docs/10_audit.md`·`docs/10_audit_b.md` 중 **collector 관련 항목만**(F-2, F-3, ⑨, C-1, H-6, H-7, H-9).
재현 시나리오와 파일:라인이 붙어 있다.

## ★ BLOCKER-A 유니버스 필터가 수집 경로에 한 번도 적용되지 않는다 (치명)

`build_universe` 는 **호출자가 없고**, collector 는 `symbols` 테이블을 **읽지 않는다**.
랭킹 출현 종목이 그대로 워치리스트가 되므로 **NOK·AMD·ASML·META·GS 같은 대형주가
정상적으로 등록된다** — 오작동이 아니라 설계대로의 결과다.

파급이 크다: 대형주가 tier2 를 차지해 **tier3 진입을 봉쇄**했고(오늘 밤 tier3 피크 4/20),
그 결과 테이프·호가 데이터가 거의 안 모였다. **지금 쌓이는 데이터는 잘못된 모집단의 것이다.**

수정:
1. `ctx.watch()`(워치리스트 등록 지점)에 **tier0 필터를 걸어라.** 필터 자체는
   `tossmon/universe/filters.py:passes_tier0` 에 이미 있다(W2 소유 — **읽어서 쓰되 고치지 마라**).
   가격·시총 판정에 필요한 `StockMeta`(발행주식수)를 어떻게 확보할지가 설계 포인트다
   (`/stocks` 배치 조회 + `symbols` 테이블 캐시).
2. collector 가 **`symbols` 테이블을 시드로 읽게** 하라.
3. `build_universe` 진입점은 **W2 에 별도 지시했다** — 너는 collector 쪽 소비만 붙여라.
   진입점 시그니처가 필요하면 `ask`.
4. **필터를 통과하지 못한 종목이 워치리스트에 있으면 로그로 드러나게** 하라.
   조용히 걸러지면 나중에 "왜 이 종목이 없지"를 추적할 수 없다.

## ★ BLOCKER-B 실시간 재판정이 라벨을 오염시키고 중복 방어 2층을 동시에 뚫는다 (치명)

세 가지가 한 뿌리다 — **실시간 검출이 과거 매매일까지 재판정**하는 것:
- **자기오염 재판정**: 전일 이벤트를 당일이 섞인 곡선으로 다시 판정해 **rvol 17.6 → 3.4** 로
  무너뜨리고, UPSERT 로 **깨끗한 기록을 덮어쓴다.**
- **RVOL 게이트가 조용히 꺼진다 (C-1)**: 승격 직후 `build_curve` 가 `None` 을 반환하고
  **그 None 이 1시간 캐시**된다 → `gated=False` 로 가격 조건만으로 이벤트가 기록된다.
  계약 A1 §6 이 막으려던 바로 그 오염이다.
- **T0 이동 → 중복 방어 2층 동시 관통 (I-1)**: 게이트가 켜졌다 꺼지면 t0 가 이른 봉 A →
  늦은 봉 B 로 **이동**한다. 두 방어층(DB UNIQUE, 검출기 해시)이 **같은 키 (symbol,t0_ms)**
  위에 있어 t0 가 움직이면 **둘 다 뚫린다.**

수정:
1. **실시간 검출을 현재 매매일로 제한하라.** 감사 판단으로는 이것 하나로 위 셋이 동시에 사라진다.
2. `build_curve` 가 `None` 일 때 **캐시하지 마라**(또는 짧은 TTL). 곡선이 없으면
   `rvol_gated=False` 로 표시되는 것 자체는 계약 A1 §6 대로 맞지만, **1시간 고착이 문제**다.
3. **두 중복 방어층 중 하나를 다른 키로 바꿔라.** 같은 키 위에 두 층을 쌓으면 층이 아니다.
   (예: 검출기 측을 (symbol, 매매일) 또는 라벨 내용 기반으로)
4. **H-6 베이스라인 동결**: 세션 전환 시 `baselines`/`prev_close`/`history_days` 를 무효화하라.
   한 줄이고, 안 고치면 다일 운영에서 라벨이 계속 틀린다. B 와 같은 뿌리다.

## 그 외 (같은 태스크에서 처리)
- **H-9 재시작 구멍 탐지**: 정전이 200 세션분을 넘으면 `candles_1m` 에 구멍이 남는데
  **아무 신호도 없다.** 1분봉은 수백 일 보관되므로 **탐지만 되면 나중에 메울 수 있다** —
  우선순위는 "완벽한 백필"이 아니라 **"구멍을 반드시 경고"** 다.
  `_backfill_1m` 이 `stop_at_ms` 에 못 닿으면 warn + replay 테스트에 구멍 단언.
- **H-7 churn**: `force()` 에 dwell 적용, 랭킹 점수를 스코어 채널에서 분리.
  BLOCKER-A 를 고치면 증상은 줄지만 플래핑 메커니즘 자체는 남는다.
- **재시도·실패 호출이 `BudgetGuard` 에 0회 계상된다** — 실사용 관측이 과소평가된다.

## 테스트 요구
항목마다 **수정 전이면 실패하는 회귀 테스트**. 특히:
- 대형주(시총·가격 기준 미달)가 워치리스트에 **등록되지 않는지**
- 전일 이벤트가 당일 곡선으로 **재판정되지 않는지**
- `build_curve` None 이 장시간 고착되지 않는지
- t0 가 이동해도 중복 행이 생기지 않는지 (두 층이 다른 키를 쓰므로)
- 백필이 목표 시각에 못 닿으면 warn 이 나는지
