# W3 — Phase 1-C 재분석 v2 (회수된 백필로 — 밤샘 캠페인 D)

너는 W3 다. 백필 앵커 결함이 수정·재실행되어 **1분봉이 177만 → 1,000만+ 로 회수**됐다
(창 4,002 전부 종결, 매니페스트 갱신). v1 에서 §1.7 감사를 발동시킨 "10% 충전"의 주범이
제거됐으므로 **전체 재분석**을 수행한다. 절차·금지는 v1 태스크
(`coordination/specs/w3_phase1c_analysis.md`)와 동일 — 아래 차이만 반영하라.

## v1 대비 차이

1. **§1.7 기저율 재검이 첫 관문**: 새 카탈로그의 기저율 5종이 문헌 대역(±15%p)에
   들어오는지부터 확인·보고하라.
   - 들어오면 → Q1~Q6 본판정으로 진행 (§4 기준 그대로).
   - 여전히 이탈이면 → **판정하지 말고** 잔여 이탈의 원인 분해(유동성 결핍 vs 기타)를
     정량화해 §2.7 개정 결정 메모 초안까지만 (개정은 사용자·W7 몫).
2. `docs/15_phase1c_report.md` 는 **v2 절 추가** 방식(v1 기록 보존 — §1.7 감사가 결함을
   잡아낸 이력 자체가 가치다). `docs/13` 시행 등록 계속.
3. 이벤트일 충전율(정규장 봉/390) 분포를 v1 대비 전/후로 리포트에 명시 — W4 의
   worker_done 비교 수치와 교차 검증.
4. 검증 깔때기 규율 유지: v2 본판정의 시행 등록·Bonferroni 적용. **홀드아웃 봉인 그대로**
   (열람은 아침 사용자 결정). Q2 는 여전히 실시간 구간 전용(§6.3) — v1 탐색 결과 인용만.
5. 백필 DB 경로 동일(`w4-collector/data/backfill.db`, 읽기 전용), 매니페스트 갱신본 사용.
