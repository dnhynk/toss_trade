# W7 — W3 가 남긴 인용 정합 4건 (문언만. 새 판정 금지)

## 배경

W3 `52a7d30`(`docs/51_anchor_boundary.md`, 오늘 머지됨)이 보고 끝에 **자기 소유 밖 4건**을
남겼다. W3 의 표현 그대로:

> 남은 것은 W7·코디네이터 소유의 요구 4건(§11-5e 문언 처리, docs/15 strict_lt 표기,
> evaluate.py:156 주석, docs/49 §6 #6 방향 진술 정정)이며 **판정은 내리지 않았고
> 문서는 고치지 않았다.**

**코디네이터 실물 확인 (오늘)**: `docs/15_phase1c_report.md` 와
`docs/15_phase1c_appendix_run_all.md` 에 `strict_lt` 문자열이 **각각 0건**이다.
즉 이 4건은 08-09 이후 **아직 아무것도 처리되지 않았다.** 보고를 믿지 않고 세어본 결과다.

## 왜 이게 문서 위생이 아니라 안전 문제인가

바로 이 계열의 사고가 **이틀 전에** 났다. `097d4a1`:

> docs/07: retire the cutoff rationale that a live spec was still using to instruct lookahead

낡은 인용 하나가 **살아 있는 스펙에게 룩어헤드를 지시하고 있었다.** 이 프로젝트에서
인용 불일치는 나중에 고쳐도 되는 것이 아니다.

## 4건

1. **`docs/48` §11-5e 문언 처리**
2. **`docs/15` (report·appendix 둘 다) `strict_lt` 표기** — 현재 0건
3. **`tossmon/analysis/evaluate.py:156` 주석**
4. **`docs/49` §6 #6 방향 진술 정정**

각 건마다 W3 의 `docs/51_anchor_boundary.md` 와 `docs/48` §11-7 을 근거로 읽어라.

## 제약 (어기면 태스크 실패로 본다)

- **새 판정 금지.** 이미 내려진 결정을 문서에 반영하는 것만 한다. 어느 한 건이라도
  "이걸 적으려면 먼저 판단이 필요하다" 로 보이면 **거기서 멈추고 escalation** 을 올려라.
  틀린 문장을 지우는 것보다 새 문장을 지어내는 것이 이 프로젝트에서 더 비쌌다.
- **`docs/12_preregistration.md` 개정 금지.** 사전등록 개정은 사용자 결정 사항이다.
  4건 중 하나라도 docs/12 를 건드려야 한다면 멈추고 escalate 하라.
- **홀드아웃(2026-05-01~07-29) 열람 금지. 검증 카드 소각 금지. 라이브 API 호출 금지.**
- **`evaluate.py` 는 주석만.** 동작을 바꾸지 마라 — 바꿔야 할 것이 보이면 그건 별개
  태스크이고, 여기서 하지 않는다.
- 각 건마다 **"무엇을 근거로 이렇게 적었는가"** 를 한 줄로 커밋 메시지에 남겨라.
