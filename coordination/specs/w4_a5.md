# W4 후속 — 계약 개정 A5 반영 (1분봉 원주가 / 일봉 수정주가)

너는 W4(`tossmon/collector/**`, `tossmon/config.py` 소유자)다. 짧은 후속 1건이다.
이전 태스크는 머지됐다(main 1f8d1ab). **라이브 리스 없음** — mock 전용
(`TOSS_LIVE=0`, `TOSS_BASE_URL=http://127.0.0.1:8899`). 리스는 현재 W5 가 보유 중이다.

## 배경 (라이브에서 실제로 드러난 문제)
W5 라이브 진단: CRKN 2025-03-05 봉이 `adjusted=true` → `0.10461614`,
`adjusted=false` → `1.9889`. 비율 ≈ 19.01 = 분할 보정.
**수정주가는 그 시점의 명목 가격을 지운다.** CRKN 은 그날 실제로 $1.99 에 거래됐는데
수정주가로는 $0.10 로 보인다. 우리 논지는 "동전주 가격대에서 벌어지는 현상"이라
수정주가로 과거를 보면 **당시 $2 종목을 동전주로 오분류**한다. 게다가 sub-penny 호가,
LULD 밴드 경계($0.75/$3) 같은 미국 제도가 전부 명목 가격 기준이다.

## 작업 (소유 경로: `tossmon/collector/**`, `tossmon/config.py`, `tests/test_collector*.py`)
1. `git rebase main` (main 은 55c7d15 이상).
2. `loops.py` 의 캔들 호출 3곳에 `adjusted` 를 **명시적으로** 넘겨라:
   - L756 `get_candles(symbol, "1m", ...)` → `adjusted=False`
   - L862 `get_candles(symbol, "1m", ...)` (백필 경로) → `adjusted=False`
   - L881 `get_candles(symbol, "1d", count=60)` → `adjusted=True`
   (줄 번호는 머지 시점 기준이라 이동했을 수 있다. **1분봉 전부 False, 일봉 전부 True** 가 규칙이다.)
3. `TossClient.get_candles` 의 기본값은 **바꾸지 마라** (W1 소유, 호출자 명시 방식이 계약이다).
4. 규칙이 코드에 드러나게 하라 — 상수나 헬퍼(`_CANDLE_ADJUSTED = {"1m": False, "1d": True}` 같은)로
   두고 호출부가 그걸 참조하게 하면 다음 사람이 한쪽만 고치는 실수를 막는다. 방식은 네 판단.
5. **테스트**: 1분봉 호출이 `adjusted=False` 로, 일봉 호출이 `adjusted=True` 로 나가는지
   검증하는 회귀 테스트를 추가하라(mock 서버 요청 파라미터 확인 또는 client 스텁 호출 인자 확인).
   규약은 테스트가 없으면 다음 사람이 뒤집는다.
6. 전체 `pytest` 통과 확인.

3. 소유 경로 밖 수정 금지. 완료 시 `git diff --name-only $(git merge-base main HEAD)..HEAD` 로 증명.
4. 거래 코드 금지.
5. 시크릿 출력·로그·커밋 금지.
6. `main` 직접 커밋·머지 금지.
7. **보고 전 `git log` 로 커밋을 확인하라.**
8. `worker_done` 정확히 1회, 보고 포맷 (a)~(e), 이후 idle.

   오늘 밤 데이터를 올바른 설정으로 받을 수 있다. 작은 변경이니 빠르게 처리하고 보고하라.
