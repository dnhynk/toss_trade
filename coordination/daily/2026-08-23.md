## 2. ★★ PR #39 loop-lag 계측 배포 — 휴장 창, `config_sig` 불변

`Clock.sleep()` 이 실제로 얼마나 더 걸렸는지를 monotonic 으로 재서 `loop_lag_max_ms` ·
`db_write_max_ms` 를 **창 게이지**로 낸다. `docs/63` §8-5 가 못 갈랐던 *"송신만 막혔나,
루프가 통째로 막혔나"* 를 가르는 자다 — 즉 §2 최대 결함을 겨냥한 물건이다.

### 2-1. 사전 확인 — 사전등록을 깨지 않는다

- `G2G3-PREREG` §2-3 의 제외 조건은 **`unobserved_frac > 0.005`** 와 **창 안 `config_sig` 변경** 둘뿐이다. 창 사이의 코드 배포를 막는 규칙은 없다.
- **이 diff 는 `config_sig` 를 안 건드린다**: `git diff 61a007c 26364a6 -- tossmon/collector/loops.py | grep config_sig` → 히트 0. 바뀌는 것은 `counter_scope` 에 `;window:` 절이 붙는 것뿐.
- **`config/` · `ops/` diff 가 비어 있다** → 운영 config 도, 배포 중 돌고 있는 `watchdog.ps1`·`supervisor.py` 도 안 바뀐다.
- `pyproject.toml` 불변 → 새 의존성 없음, `.venv` 손 안 댐.
- `counter_scope` 를 읽는 코드는 **테스트 4 개와 `loops.py` 자신뿐**이다. `tools/d21_verdict.py`·`ops/**` 는 안 읽는다. 테스트가 쓰는 `split(";")[0]` 은 여전히 `proc:` 절을 준다.

## 6. 하드웨어 이동 뒤 토스 IP 화이트리스트 — **재등록 필요 없다. 실측으로 닫았다**

사용자 물음: *"하드웨어 이전했는데 토스 허용 API 추가 안 해도 되나? 와이파이 똑같아서."*

**안 해도 된다.** 토스가 화이트리스트에 거는 것은 **공인 IP**(공유기가 ISP 에서 받은 주소)다.
기계의 사설 IP 는 NAT 뒤라 토스에 아예 안 보이므로 **같은 공유기면 기계 교체가 토스 쪽에서
구분되지 않는다.**

### 6-1. 근거 — 이동 전후 정규장 대조

```
08-20 정규장 (이동 전)  distinct_snap = 5,545   22:30:02 ~ 04:59:49 KST
08-21 정규장 (이동 후)  distinct_snap = 5,577   22:30:00 ~ 04:59:52 KST
```

이동은 **08-21 19:27~22:26**. **그 직후 세션이 온전히, 오히려 더 깨끗하게 수집됐다** —
새 기계에서 토스 응답을 5,577 번 받았다는 뜻이다.

로그 전수: `Forbidden`/`403` **0 건**, `auth_failures` 는 로그 전체에서 **distinct 값이 0 하나뿐**.

> ⚠ 08-21 18:45 의 `AUTH-FAILURE` 줄을 IP 거절로 읽지 마라. 본문이
> *"token lease already held by another process … refusing to issue"* — **토큰 1 개 제약을
> 지키는 우리 쪽 가드**이고(중복 사슬 건), 시각도 이동 **전**이다.

### 6-2. 기록해 둔 것과 그 이유

**공인 IP `124.49.14.184`** (2026-08-23 13:3x, 제공자 둘 일치) 를 `COORDINATOR-STATE` 위 표에
넣었다. **비교 기준이 없어서** 지금까지는 *"IP 가 바뀐 건가"* 를 로그로 역추적해야 했다.

**이 값이 낡는 것 자체가 신호다.** 공인 IP 는 기계와 무관하게 바뀐다 — ISP DHCP 갱신,
공유기 전원 차단·재부팅, ISP 점검. 바뀌면 즉시 드러난다:

```
전 요청 403 -> Forbidden 예외 / fetch_success_pct 100 -> 0 / 워치독 auth_fail != 0
```

**탐지는 이미 걸려 있다.** 403 을 보면 **먼저 위 표의 IP 와 현재 IP 를 대조해라** —
그러면 "화이트리스트냐 아니냐"가 한 번에 갈린다.
