## 3. ★★ 돌리기 전에 찾은 것 — **확증 모드가 없었다**

명세 없이 코드를 열어보니 내가 예상한 것(*"바닥 상수가 08-13 이라 버린 셋이 섞인다"*)
보다 나빴다. **가드 둘이 전부 `exploration_only` 전용**이고 `exploration_only=False` 는
팔을 안 가리는 `unrestricted` 였다 — `arm.name` 이 그 이름을 리터럴로 갖고 있었다.

```python
if exploration_only:  until = min(until, FLOOR-1)   # 탐색 전용
if exploration_only:  sessions = [탐색 9 세션만]     # 탐색 전용
# exploration_only=False -> 가드 0 개
```

그대로 판정을 돌렸으면 **버린 셋(08-13·14·17)과 탐색 9 세션이 예외도 경고도 없이
섞였다.** 수정 내역은 `docs/67` §6.
