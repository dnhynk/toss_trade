## 0. 한 장 결론 — **B+ 를 권고했고, 사용자가 B+ 를 골랐다 (2026-08-27)**

지금 G-3 이 얼린 최소 비용은 $100 주문의 **2.38%** 다. 그러나 이것은 실체결 비용이 아니라
호가 스냅샷으로 만든 **추정**이고 실체결은 **0건**이다. 그 뒤 탐색 B 에서 관측된 크기는
`docs/74` 주 경로 B **+1.856%p**, 반증 전용 C **+1.345%p** 였다. 두 수 모두 2.38%보다
작다. 다만 이 병치는 **크기 감각만** 준다. `docs/74` 는 두 경로 모두 사전등록 통과선에
**미달해 축을 닫았고**, C 는 판정 경로도 아니며, 어느 수도 거래 가능한 알파나 G-3 판정 수가 아니다.

**갱신 권고는 B+** 다. `docs/21` 의 B 방향(상태를 T0 에 고정하고 `cross` 를 판정에,
`mid` 를 민감도에 쓰는 것)을 유지하되, 뒤에 확인된 주문 크기 효과도 버리지 않는다. 공동
`상태 × 크기` 실체결 표가 없으므로 둘을 더해 가짜 정밀도를 만들지 않고, **각 크기의 현행
추정과 해당 상태의 `cross` 추정 중 큰 값을 보수적 판정 문턱으로 쓰는 정책**을 제안한다.
이 값은 실제 비용의 추정치가 아니라 서로 다른 두 위험축을 모두 밑돌지 않게 하는 **판정 문턱**이다.

동시에 B+ 는 숫자의 진실성을 주장하지 않는다. 비용을 낮추거나 실자본으로 넘어가는 문은
**D-2 실체결**만 열 수 있게 둔다. 페이퍼 트레이딩은 신호·주문 논리·시각 정합을 시험할 수
있지만 실제 체결가·부분체결·취소·SOR 품질을 실측하지 못한다.

사용자가 답할 문장은 하나다.

- **A** — 현행 네 추정치를 그대로 G-3 최종 문턱으로 쓴다.
- **B+ (권고)** — 상태·크기 보수 문턱으로 개정하고, 하향 갱신과 실자본은 D-2 로만 연다.
- **C** — 현행 표는 임시 화면에만 쓰고, D-2 전에는 G-3 비용 재판정과 실자본 승인을 보류한다.

이 문서가 선택을 대신하지 않았다.

## 1. 지금 얼린 네 숫자는 어디서 왔나

`coordination/G2G3-PREREG.md` §4-1 은 다음 표를 얼렸다. **이 문서에서도 숫자를 바꾸지 않는다.**

| 주문 크기 | 얼린 왕복 비용 |
|---:|---:|
| $100 | **2.38%** |
| $500 | **4.45%** |
| $1,000 | **4.91%** |
| $2,000 | **6.44%** |

출처의 계보는 `docs/18` §4 의 2026-08-03 갱신 → `docs/22` §B-2 다. W5 가 처음 켠
tier-2 호가의 **1 매매일·879 스냅·81종목**에서, 가장 큰 $2,000 주문까지 보이는 매도호가가
소진되지 않는 깊은 스냅 **628건**만 남겨 `size_cost_curve(require_unexhausted=True)` 를
실행했다. 한 스냅의 최대 10단계 호가에서 진입은 ask, 이탈은 bid 를 즉시 걷는 `cross` 로
가정하고 왕복 수수료 **0.2%** 를 더한 뒤 중앙값을 냈다. 그래서 이 표가 직접 보여주는 것은
**주문 크기가 커질수록 표시 호가를 더 걷는 기울기**다. $100 에서 $2,000 으로 갈 때 추정이
2.38% → 6.44% 로 커진다.

이 표를 실제 비용으로 읽으면 안 되는 이유도 같은 측정에 들어 있다.

1. **깊은 호가창 조건부다.** $2,000 까지 보이는 매도호가가 남은 스냅만 쓰므로 비용의
   수준은 낙관 쪽으로 선택됐다. `docs/22` 도 수준이 아니라 기울기를 읽으라고 적었다.
2. **한 시점의 표시 호가를 왕복한다.** 주문을 보내는 동안 호가가 움직이는 동적·실현
   슬리피지, 네트워크·브로커 지연, SOR 의 숨은 유동성이나 불리한 라우팅을 재지 않았다.
3. **미체결분의 비용을 만들지 않는다.** 보이는 호가가 소진되면 체결 가능 부분만 계산한다.
   실제 부분체결, 잔량 대기, 취소·정정·거부, 체결까지 걸린 시간과 기회비용은 표 밖이다.
4. **환전 스프레드는 없다.** 달러 잔고 유지가 사용자 확정이라 회전마다 0.3%를 넣지 않았다.
   실제로 원화↔달러를 바꾸는 현금흐름이 생기면 그 거래의 스프레드는 별도로 재야 한다.
5. **세금은 없다.** `docs/00` §1-5 의 양도세 **22%(연 250만원 초과분)**와 **손실
   이월공제 없음**은 세후 복리의 비대칭이지만 이 왕복 비용표에는 들어 있지 않다.

따라서 개정 7 의 정정이 정확하다.

> ~~실측 왕복 비용~~ → **호가 스냅샷 왕복 비용 추정(실체결 0건)**

개정 7 은 라벨만 고쳤고 네 숫자와 “네 크기 전부에서 판정” 규칙은 바꾸지 않았다. 실제로
그 숫자를 바꾸는 결정은 여전히 D-1 하나다.

## 2. 2026-08 초 뒤에 배운 것 — B 의 방향은 강화됐고 숫자의 확실성은 약해졌다

### 2-1. 관측된 차이는 비용 추정과 같은 자릿수보다 작다

`docs/71` 의 탐색 차이는 **+1.546%p** 였고 CI 하한이 그 축의 +0.91%p 통과선에

바꿔 읽을 수 없다.

그럼에도 비용 결정에는 크기 감각을 준다. 지금 본 차이가 대략 **+1.3~1.9%p**인데, 가장
작은 주문의 비용 추정부터 **2.38%** 다. 비용 전제를 1%p 움직이는 것은 주변부 정리가 아니라

반대로 `docs/18` 의 비용이 실체결이 아니라는 개정 7 은 B 의 옛 근거 문장을 약화한다.

### 2-2. 주문 크기 축이 생겼다

옛 B 는 가격대 × 시장 상태를 고정하면 된다고 썼다. 이후 tier-2 호가에서 **주문 크기만으로

공동 `가격대 × 상태 × 크기` 실체결 표는 없다. 두 추정을 더하거나 비율로 외삽하면 근거 없는

## 3. 크기 감각 — **병치이지 알파 판정이 아니다**

아래는 단위를 나란히 놓은 산술이다. 서로 다른 대상을 빼서 거래 손익을 만든 표가 아니다.

| 항목 | 관측/추정 크기 | 2.38%와의 단순 거리 | 올바른 지위 |
|---|---:|---:|---|
| `docs/74` B 평균 차 | **+1.856%p** | 2.38 − 1.856 = **0.524%p** | 주 경로지만 통과선 **미달**, 축 닫힘 |
| `docs/74` C 평균 차 | **+1.345%p** | 2.38 − 1.345 = **1.035%p** | 반증 전용·판정 불가, 통과선 **미달** |
| 현행 최소 비용 | **2.38%** | — | 호가 스냅샷 추정, 실체결 0건 |

`docs/74` 의 수는 5분 `max_ret` 의 실제−위약 차이고, 비용은 주문 원금 대비 왕복 비율이다.
차이는 거래 가능한 총수익이 아니며, 진입·이탈 규칙·체결 확률·세금까지 합친 net 도 아니다.
따라서 “B 는 1.856% 벌고 비용이 2.38%라 0.524% 잃는다”는 계산은 **금지**다. 말할 수 있는
것은 **비용 전제의 최소치가 최근 관측 차이보다 큰 자릿수**라는 것뿐이다.

선택에 따라 크기 감각은 이렇게 달라진다.

| 선택 | $100 에 놓이는 문턱/상태 | +1.856%p·+1.345%p 옆에서 보이는 것 |
|---|---|---|
| A | 현행 **2.38% 추정** | 둘 다 그보다 작다. 실제 비용 오차는 그대로 열린다 |
| B+ | `$2~5·움직이는 중`이면 `max(2.38, 3.22)` = **3.22% 정책 문턱** | 둘 다 문턱보다 더 작다. **3.22%도 추정**이며 알파 판정은 아니다 |
| C | D-2 전에는 최종 문턱을 확정하지 않음 | 실제 체결 표본이 생길 때까지 비교 자체를 보류한다 |

B+ 의 예에서 $500/$1,000/$2,000 은 `max(현행 크기 추정, 3.22%)`라 각각
**4.45% / 4.91% / 6.44%**가 된다. 전 밴드·움직이는 중 `cross` 6.94%를 적용해야 하는
상태라면 네 크기 모두의 정책 문턱은 적어도 6.94%다. 이것은 **제안된 정책의 예시**이고,
§4-1 의 얼린 숫자를 고친 것이 아니다.

## 4. 선택지와 대가

### A — 현행 네 추정치를 최종 G-3 문턱으로 유지

- **무엇을 바꾸나**: 아무것도 바꾸지 않는다. 네 크기 모두에서 2.38/4.45/4.91/6.44%를
  차감하고 현 사전등록의 최초 판정을 낸다.
- **얻는 것**: 가장 빠르고 비교 규칙이 단순하다. 현재 사전등록의 보호 아래 최초 판정을 낸다.
- **대가**: 실체결 0건, 깊은 호가창 선택, 동적 슬리피지·부분체결·취소·환전·세금 누락을
  그대로 최종 문턱에 받아들인다. 상태축도 버린다.
- **되돌릴 수 없는 것**: 나중에 D-1 을 열어 재판정할 수는 있지만, `G2G3-PREREG` §4-1 이
  명시했듯 **현재 사전등록의 보호는 재판정에 따라가지 않는다**. 이 전제로 규칙을 고르고
  1회성 검증·홀드아웃을 열면 그 기회는 복구되지 않는다.

### B+ — 상태·크기 보수 문턱으로 개정하고 D-2 를 하향 잠금으로 둠 (**권고**)

옛 B 가 바꾸자던 것은 `docs/12` §2.6 의 단일 1.0%를
`왕복 수수료 0.2% + T0 가격대·과거 시장 상태에 고정된 집행 비용`으로 바꾸고, 판정·선별에는
즉시성을 보장하는 `cross`, `mid`는 민감도에만 쓰자는 것이었다. 이벤트별 유리한 칸 사후 선택,
수익을 본 뒤 비용 조정, 홀드아웃 뒤 소급 적용을 금지하고 구 1.0% 열을 비교용으로 남기는 안이다.

B+ 는 여기에 뒤늦게 확인된 **주문 크기**를 넣는다.

- **무엇을 바꾸나**: 각 G-3 크기에서 `max(현행 크기 추정, T0 에 기계 배정된 상태·가격대
  cross 추정)`를 **판정 문턱**으로 쓴다. 공동 셀이 없거나 상태 배정이 불가능하면 유리한
  칸으로 대체하지 않고 **판정 보류**다. `mid`와 현행 네 숫자는 민감도·비교 열로 함께 낸다.
- **얻는 것**: 크기축과 “움직이는 순간이 비싸다”는 상태축 어느 쪽도 무시하지 않는다.
  후보 선별부터 같은 문턱을 써서 낙관 비용으로 검증 자리를 낭비하는 옛 C 의 문제도 막는다.
- **대가**: 서로 다른 1일 표본 두 개의 추정 중 큰 값을 쓰므로 보수적이지만 실제 비용의
  일치 추정량은 아니다. 실제 SOR 가 더 싸다면 참전략을 기각할 수 있고, 통과는 A보다 어렵다.
- **하향 잠금**: 비용 문턱을 낮추는 갱신과 실자본 승인은 사전 설계된 D-2 실체결만 허용한다.
  페이퍼 체결이나 수익률 결과로 낮추지 않는다.
- **되돌릴 수 없는 것**: 이것은 열람 후 실효 문턱을 바꾸는 개정이다. B+ 로 낸 재판정은
  현재 사전등록과 같은 보호를 주장할 수 없다. 비교 열을 남겨도 그 보호가 복구되지는 않는다.

### C — 실체결 우선: D-2 전에는 최종 비용 재판정과 실자본을 보류

- **무엇을 바꾸나**: 현행 네 숫자는 임시 화면·민감도에만 남긴다. 신호·주문 시스템은
  페이퍼로 시험할 수 있지만, D-2 표본이 생기기 전에는 비용 전제를 확정해 G-3 를 재판정하거나
  실자본을 승인하지 않는다.
- **얻는 것**: “추정을 실측으로 부른다”는 오류를 가장 확실히 피한다. D-2 가 실제 브로커
  경로에서 무엇을 좁혔는지 본 뒤 문턱을 사전등록할 수 있다.
- **대가**: 가장 느리다. 사용자가 D-2 를 “전략이 어느 정도 보장된 뒤”로 유예한 순서를
  존중하면 G-2/신호 후보와 비용 최종판 사이에 대기 구간이 생긴다. 작은 $100~200 주문은
  낮은 크기만 답하고, 네 크기를 모두 좁히려면 단계별 실제 주문과 반복이 필요해 위험이 커진다.
- **되돌릴 수 없는 것**: D-2 의 실제 주문·체결·손익·세금 사건은 되돌릴 수 없다. 반면
  기다리기 자체는 판정 규칙을 열지 않지만 시간과 기회를 쓴다.

### 주 선택지에서 뺀 옛 C·D

- 옛 **C**(1.0%로 후보를 고르고 마지막 승인에만 높은 비용을 추가)는 마지막 문턱은 높여도
  낙관 비용으로 깔때기를 먼저 소모한다. B+보다 얻는 것은 적고 복구 불가능한 선별 위험은 커서
  주 선택지에서 뺐다.
- 옛 **D**(호가 수집일을 더 쌓고 개정)는 호가 추정의 안정성에는 유효하지만 실제 체결 품질을
  열지 못한다. 필요한 지연 선택지는 D-2 를 명시한 새 C 가 대신한다.

## 5. 비용을 실제로 좁히는 두 길 — 페이퍼와 D-2 는 답이 다르다

| | 페이퍼 트레이딩 | D-2 계측 전용 실주문 |
|---|---|---|
| 실제 돈 | 없음 | **있음** — 실제 주문·손익·시장 노출 |
| 답할 수 있는 것 | 신호 도착·주문 생성·취소 논리·시각 정합·호가 대비 가상 손익·비용 가정별 민감도·운영 장애 | 테스트한 브로커·주문 유형·크기·상태에서 실제 체결 여부, 체결가, 지연, 부분체결, 취소/정정 결과, 결정 호가 대비 실현 shortfall |
| 답할 수 없는 것 | 실제 SOR 경로, 숨은 유동성, 큐 순위, 실제 체결 확률·부분체결·시장충격·실현 슬리피지. 비용 모델로 가상 체결하면 그 모델을 되돌려 받을 뿐 | 적은 표본 밖의 모든 종목·세션·크기, 장기 알파, 미체결 주문의 완전한 반사실, 환전하지 않은 환전 스프레드, 연간 세후 복리 |
| 얼마나 좁히나 | **실체결 비용은 구조적으로 못 좁힌다.** 신호와 시스템 오차를 분리해 D-2 설계를 정확하게 한다 | 0건을 실제 표본으로 바꾸고 테스트한 셀의 범위를 좁힌다. $100~200만 하면 2.38% 근처만 검증하며 $500/$1,000/$2,000으로 외삽하면 안 된다 |
| 대가 | 시간·운영 복잡도. 노출된 페이퍼 결과로 규칙을 다시 고르면 새 사전등록이 필요 | 실제 손실·부분체결·세금 사건 가능성. 네 크기·여러 상태를 반복할수록 비용과 위험 증가 |

`docs/18` §6 의 “SOR 이 보이지 않는 유동성에 접근하면 나아질 수 있다 — 페이퍼 트레이딩
실측으로만 풀린다”는 문장은 **라이브 호가 위에서 집행 파이프라인을 시험하는 단계**로 읽어야
한다. 브로커의 모의 체결이 실제 SOR 체결을 재현한다는 증거는 없다. 실제 체결 품질을 숫자로
낮추는 근거는 `USER-INPUT-QUEUE` D-2 가 적은 **계측 전용 실주문**이다.

D-2 를 택하더라도 먼저 얼릴 것이 있다: 주문 유형(사용자 확정인 SOR+지정가), 크기, T0
상태, 결정 호가, 주문·승인·부분체결·취소 시각, 최대 대기시간, 중단선, 그리고 어떤 표본이면
어느 비용 셀만 갱신하는지다. 이 문서는 프로토콜을 제안할 뿐 실행하지 않는다.

## 6. 사용자가 고를 문장과 불가역 경계

아래 중 하나를 그대로 답하면 D-1 이 열린다.

1. **`D-1 A`** — 현행 네 호가 추정치를 G-3 최종 비용 문턱으로 유지한다.
2. **`D-1 B+`** — 상태·크기 보수 문턱으로 개정한다. 비용 하향과 실자본은 D-2 실체결로만 연다.
3. **`D-1 C`** — D-2 전에는 G-3 비용 재판정과 실자본 승인을 보류한다.

**권고는 2번 B+** 다. 근거는 최근 관측 차이가 비용 추정과 같은 자릿수이고, 수집 예산을 더
써도 실제 체결은 생기지 않으며, B+가 두 추정축을 버리지 않으면서도 비용을 낮추는 문은 D-2에
잠그기 때문이다. 다만 정확성보다 실체결 근거를 우선하고 지연·실위험을 감수할 의향이 있다면
C 가 더 강한 증거 순서다.

사용자가 무엇을 고르든 다음은 자동 승인되지 않는다.

- 이 선택만으로 `docs/12`·`docs/13`·`G2G3-PREREG` §4-1 을 수정하지 않는다. 선택 뒤 별도
  개정 기록이 필요하다.
- 이 선택만으로 D-2 주문, 페이퍼 트레이딩, 검증 카드, 홀드아웃, Phase 2 를 열지 않는다.
- 이미 데이터가 보인 뒤 바꾼 문턱으로 낸 재판정에는 현재 사전등록의 보호가 따라가지 않는다.

**이 작업에서 실행한 것은 없다.** 실제 주문 0, 라이브 API 0, DB 접근 0, 수집기 변경 0,
확증 팔·홀드아웃 열람 0이다.
