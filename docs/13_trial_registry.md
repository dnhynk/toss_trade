# 13 — 시행 레지스트리 (trial registry)

> 소유: W3. **추가 전용(append-only)** — 행 삭제·수정 금지. 정정은 새 행 + 참조로 한다.
> 근거: `docs/12_preregistration.md` §5. 이 파일에 없는 수치는 리포트에 실을 수 없고
> Phase 2 근거로 쓸 수 없다.
>
> **세는 대상**(§5.1): `detect_events` 또는 `evaluate.q*` 를 새로운 (파라미터, 기간,
> 조건부 규칙, 피처 정의) 조합으로 실행하고 **그 결과 수치를 사람이 본 순간** 1행.
> 폐기한 것, "잠깐 본" 것, 버그로 다시 돌린 것(사유 기록) 전부 포함한다.
>
> **깔때기**(§5.3): 훈련 무제한 → 검증 ≤5 → 홀드아웃 1.
> 통계 보정: 검증 단계 후보 간 비교는 Bonferroni α = 0.05/5 = 0.01,
> 홀드아웃은 α = 0.05 단일 검정 + Bonferroni 병기.

**v2 시행(T-013~T-019)의 깔때기 비소모 근거** — §5.3 의 "검증 ≤5" 슬롯은 **§4.5-2/3 의 Q5 조건부
규칙 후보가 검증 기간으로 진출하는 것**을 세는 장치다. T-013~T-019 는 (i) 조건부 규칙 후보가
아니고(탐색 미착수), (ii) 어떤 accept/reject 판정도 내지 않았으며, (iii) §1.7 관문 미통과로
판정 자체가 금지된 상태다. 따라서 슬롯 비소모로 처리한다. T-017·T-018 은 검증 기간(val)
수치를 **보았으므로** §5.1 에 따라 등록했다 — 등록과 슬롯 소모는 별개다. 이 해석이 W7 판단과
다르면 정정 행을 추가한다(행 수정 금지 원칙).

**T-012 의 깔때기 비소모 근거 (§5 문언 대조)** — 판단 근거를 남겨 감사 가능하게 한다:

- §5.1 은 "평가 행위 전부를 **등록**하라"고 규정한다. T-012 는 **등록했다**(위 표).
- §5.3 의 "검증 ≤5" 슬롯은 **§4.5-2/3 의 Q5 조건부 규칙 후보가 검증 기간으로 진출하는 것**을
  세는 장치다. T-012 는 (i) Q5 규칙 후보가 아니고, (ii) 검증 기간(2026-01-01~04-30)이 아닌
  **라이브 구간**을 봤으며, (iii) 어떤 accept/reject 판정도 내지 않았다.
- 따라서 슬롯 비소모로 처리한다. 이 해석이 W7 판단과 다르면 T-012 를 소모로 재분류하고
  정정 행을 추가한다(행 수정 금지 원칙에 따라 새 행으로).

Bonferroni: 검증 단계 후보 간 비교가 아직 없으므로 α 보정 적용 대상 없음.
홀드아웃 판정 시 α=0.05 단일 + Bonferroni(0.05/5=0.01) 병기 의무는 그대로 유효하다.
