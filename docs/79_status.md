## 3. `max_ret_300s` 가 무엇인지

`ruler_bias.py` `bar_forward_at` 원문:

```
진입가  = t0 다음 1분봉의 시가(open)
max_ret = (그 뒤 5개 봉의 고가 중 최댓값) / 진입가 − 1
```

**산술적 사실**: 이 값은 5 분 안의 최고가에 판 경우다. 따라서 **실현 가능한 어떤 청산
규칙도 이 값을 넘을 수 없다.** 체결·스프레드·호가 깊이·수수료·부분체결은 들어 있지 않다.

위 §2 의 수는 **사건과 정합 위약의 차**다. 경로 B 의 정합 키는 `crv5`(직전 변동성) 밴드와
`cnbar5`(직전 봉 수) 정확일치다. `docs/76` §3 은 이 수에서 비용을 빼는 계산을 **금지**한다.
