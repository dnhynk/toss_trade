# 16 — 전략 설계 노트 (Phase 2 씨앗)

> 사용자·코디네이터 토론 기록. 사전등록(docs/12)의 검증 대상이 아니라 **설계 방향의
> 정본**이다. 갱신은 토론 합의로만.

## 논제 (2026-08-02 사용자 확정)

토스 급등주 리스트·커뮤니티발 한국 개미 유동성은 그날 장의 러너들 사이를 순간순간
옮겨다닌다. 이 이동을 스크립트 레벨 레이턴시로 포착해 **아주 얇게 발라먹는다**.
- 예측이 아니라 **빠른 감지 + 짧은 편승(분 단위) + 빠른 이탈**. 욕심 금물(덤프 방지).
- 급등 전조 탐지는 사이드 알파 (필터를 아주 좁힌 경우만).

## 확정된 설계 원칙 (2026-08-02)

1. **집행은 SOR + 지정가만.** 시장가 금지 — 수직 구간 시장가는 2%+ 슬리피지 실측 문헌.
   지정가 상한으로 체결을 예측 가능하게.
2. **회당 물량은 최우선 호가 잔량 이하 소액** ($500~2,000 급). 이 전략의 알파 원천이
   "시장을 움직이는 자본의 시작점이 낮은 동네"라는 것 — 소액이 입장권이다. 기관 불가.
3. **진입 타이밍 vs 스프레드 절약은 미결 — 측정으로 푼다.** 첫 수직 분을 피하면
   스프레드를 아끼지만 움직임을 놓친다. 수집 중인 호가 1레벨 스냅으로 승격 순간 전후
   스프레드 동학을 실측해 진입창을 데이터로 정한다.
4. **세션별 진입 가중치.** 주간장(Blue Ocean: 스프레드 2.4배·깊이 절반·MM 2곳·
   2024-08 셧다운 전례)과 정규장은 비용·리스크가 다르다. "주간장 신호가 정규장으로
   이어지는가"와 세션별 가중치는 실시간 수집 축적으로 계산.
5. **보유 시간 동적화** — 고정 보유가 아니라 유동성 상태로 이탈. Q4(덤프 속도) 결과가
   이탈 설계의 재료.

## 비용 전제 (2026-08-02 리서치, 출처는 docs/15 부록)

- 환전 0.3%는 회전 비용 아님 (달러 잔고 유지).
- 현실 왕복: 정규장 서지 ~1.7% (수수료 0.2 + 슬리피지 편도 ~0.75×2), 주간장 ~3.2%.
- → **회전당 목표 폭 하한: 정규장 2%+, 주간장 4%+** (또는 그 이하 비용이 실측되면 갱신 —
  SOR·지정가 체결 품질은 실전 데이터로 재느 것이 정확).

## 규칙 후보 풀 (§4.5 2단계 탐색용 — 검증 카드 5장은 **작동 원리가 다른 것**으로 배분)

사용자 실전 감각 우선순위 (2026-08-02):
1. **랭킹 상승 속도** — "기억에 남아 있다". d(rank)/dt, 12초 해상도로 계산 가능.
2. **유동성 점유율** — "매우 크게 각인". 스냅 구간 거래대금 flow 중 해당 종목 몫.
3. **거래량 기울기** — 절대량은 시총 대비로, 기울기가 추가 신호일 것.
4. **개미털기(과매도) 진입** — 급락 후 반등 구간. 판별 난제 = 털기 vs 사망.

코디네이터 제안: 유동성 인계(A사망→B점화), 정지(halt) 재개 직후, 2차 파동,
세션 인계(주간장→정규장). 원리가 각각 속도/반전/회전/구조/시차로 달라 카드 분산에 적합.

**데이터 적합성 확인 완료 (2026-08-02, 코디네이터 실측)**: `rankings_snap` 에
**4개 리스트 × top100 × ~12초** — MARKET_TRADING_AMOUNT/VOLUME 과
**TOSS_SECURITIES_TRADING_AMOUNT/VOLUME**. `amount_u` 는 **누적** 거래대금(차분 = 구간 flow).
→ 랭킹 속도·점유율 모두 계산 가능. **핵심**: 토스 전용 리스트와 시장 전체 리스트를 동시에
갖고 있으므로 **둘의 괴리 = 토스 개미 쏠림의 직접 측정**(대리지표가 아님). 한계: top100
절단(리스트 진입 전까지 불가시) — 절단을 특성화할 것(진입 자체를 이벤트로).

## 열린 질문 (데이터로 풀 것)

- 승격/랭킹 진입 순간의 스프레드 궤적 (벌어짐→눌림 타이밍).
- 주간장 유동성 이동의 정규장 지속성.
- 짧은 보유(1·3·5분) 구간 수익 분포 — 실시간 수집분에서.
- SOR 실제 체결 품질 (Phase 2 페이퍼 트레이딩에서 실측).
