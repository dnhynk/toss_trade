# Phase 1 — 급등 전조 감시 시스템 설계 (실매매 이전 단계)

목표: 실제 급등(runner)들이 급등 **이전에** 어떤 거래량/시세/토스 유동성 전조를 보이는지
데이터로 확정한다. 이 단계의 산출물은 (a) 자체 수집 시계열 DB, (b) 라벨링된 급등 이벤트 카탈로그,
(c) 전조 신호별 리드타임·적중률 통계다. 이것이 Phase 2(실매매 모델)의 근거가 된다.

## 1. 티어드 감시 구조

폴링 예산(rate limit)이 유한하므로 좁아질수록 자주 보는 깔때기 구조로 설계한다.

```
Tier 0: 유니버스 (수천 종목, 일 1회 갱신)
  소스: 외부 심볼 디렉토리(NASDAQ Trader 등) + 랭킹 출현 종목 누적
  필터: 보통주(STOCK/FOREIGN_STOCK), status=ACTIVE, 가격 $0.1~$20,
        시총 $10M~$300M 중심 (lastPrice × sharesOutstanding; Xu&Livshits에서 시총이
        펌프 타깃 예측 1위 피처), ETF/ETN 제외
        → /stocks 배치 200개씩으로 메타데이터 수집
  보강 태그(외부 소스): float(<50M 스윗스팟), 리버스 스플릿 이력, $1 컴플라이언스
        데드라인, EDGAR 희석 파일링(S-3/ATM/424B5) — 02_theory §4.3

Tier 1: 광역 워치 (500~1,500 종목)
  동전주/저시총 + former runner(최근 N개월 내 일중 ±30% 이상 경험 종목)
  폴링: /prices 배치 200개 → 30~60초 주기 가격 스윕 (MARKET_DATA 예산의 일부만 사용)
        /candles 1d — 일 1회, 베이스라인(평균 거래량·ATR·가격대) 갱신
  승격 조건: 가격 z-score, 랭킹 진입, 1분봉 스윕에서 거래량 이상 감지

Tier 2: 활성 워치 (100~300 종목)
  폴링: /candles 1m — 종목당 60~120초 주기 (CHART 예산 5/s의 60~70%)
  계산: RVOL(시간대 보정), 거래량 z-score, VWAP 괴리, 상승 지속성
  승격 조건: 전조 스코어 임계 초과

Tier 3: 집중 감시 (10~30 종목)
  폴링: /candles 1m 매 20~30초 + /trades 매 5~10초 + /orderbook 매 5~10초
  계산: 체결 크기 분포 변화(소액 리테일 체결 비중), 테이프 버스트,
        호가 불균형, 스프레드, 틱 방향 비율
```

랭킹 폴링(별도 예산 5/s): US realtime `MARKET_TRADING_AMOUNT/VOLUME` + `TOSS_SECURITIES_TRADING_AMOUNT/VOLUME` 4종을 10~15초 주기로 스냅샷 → 전 티어의 승격 트리거 겸 **토스 쏠림도(Toss/Market 거래대금 비율)** 시계열 축적.

### 폴링 예산 검증 (보수적 배분, 한도의 70%만 사용)

- MARKET_DATA 10/s: Tier1 가격 스윕(1,500종목=8콜/60s≈0.13/s) + Tier3 trades/orderbook(30종목×2콜/7.5s≈5.3/s) ≈ 5.5/s ✅
- MARKET_DATA_CHART 5/s: Tier2(300종목/90s≈3.3/s) + Tier3(30종목/25s≈1.2/s) ≈ 4.5/s → 티어 크기로 조절 ✅
- RANKING 5/s: 4콜/12s ≈ 0.33/s ✅

429 응답 시 `Retry-After` 준수 + 그룹별 토큰버킷을 클라이언트에도 구현.

## 2. 수집 데이터 스키마 (SQLite → 필요 시 Parquet 아카이브)

- `symbols` — 메타데이터 (sharesOutstanding, market, listDate, 시총, 티어, former_runner 이력)
- `candles_1m` — (symbol, ts, o/h/l/c, v) : **핵심 자산. 보관 기간 제한 대비 자체 축적**
- `candles_1d` — 베이스라인용
- `rankings_snap` — (ts, type, duration, rank, symbol, tradingVolume, tradingAmount, changeRate)
- `trades_snap` — Tier 3 체결 (중복 제거 키: symbol+ts+price+volume)
- `orderbook_snap` — Tier 3 호가 (bid/ask 상위 N레벨, 불균형 지표는 계산 후 저장)
- `events` — 라벨링된 급등/급락 이벤트 (아래 3절)
- `promotions` — 티어 승격/강등 이력 (감지 로직 자체의 리드타임 평가용)
- `filings` — (선택, 2단계) EDGAR 희석 관련 파일링 (S-1/S-3/424B5/ATM) 종목 태그

## 3. 이벤트 정의와 라벨링 (사후 분석의 핵심)

**급등 이벤트 (초기 정의, 데이터로 보정)**:
- 30분 내 +15% 이상 또는 당일 +30% 이상, AND 당일 RVOL ≥ 3~5
  (문헌 보정: Kamps 균형 세트 = 거래량 3~4배 + 가격 +5~10%가 정밀도 스윗스팟 — 02_theory §1.1)
- 이벤트 시점 T0 = 조건 최초 충족 1분봉

**라벨 필드**: T0, 피크(HOD) 시각/수익률, 피크 후 30분/종가 되돌림률, 지속시간,
VWAP 대비 종가 위치, 플로트 로테이션 도달률, 세션(데이/프리/정규/애프터),
토스 랭킹 최초 진입 시각(T0 대비 리드/래그), 다음날 갭,
(수동 보강) 뉴스/공시/희석 여부, LULD 홀트 횟수, SSR 발동 여부.

**기저율 사전지식 (우리 데이터로 재검증할 대상, 02_theory §2.4)**:
프리마켓 대량거래 갭퍼의 페이드율 71.5%, 50%가 HOD 대비 -20% 붕괴,
73%가 VWAP 아래 마감, HOD의 63%가 10:00 ET(≈한국 자정) 이전 형성.

**전조 피처 (T0 이전 구간에서 추출)**:
- T-5/-15/-30/-60분 거래량 z-score, RVOL 궤적
- 가격 궤적: 저변동 수축(coil) 후 폭발 vs 즉발형
- 테이프: 체결 건수 증가율, 평균 체결 크기 변화 (Tier 3 데이터가 있을 때)
- 호가: 스프레드 축소, 매수호가 잔량 증가
- 토스 쏠림도: TOSS/MARKET 거래대금 비율의 레벨·기울기
- 이력: former runner 여부, 최근 N일 내 이벤트 횟수

**핵심 검증 질문 (Phase 1이 답해야 하는 것)**:
1. 거래량 이상은 가격 급등보다 평균 몇 분 선행하는가? 임계값별 정밀도/재현율은?
   (La Morgia: 정보 대부분은 시작 직후 수 초의 체결 버스트에 있고 사전매집 관찰은 드묾 —
   그렇다면 "전조 탐지"보다 "시작 후 수 분 내 확인-진입"이 현실적일 수 있음)
2. **토스 랭킹 진입은 가격 대비 선행인가 후행인가?** (Barber 2022 로빈후드 증거는 후행 =
   어텐션 피크가 청산 카운트다운임을 시사. 후행 확인 시 랭킹은 exit-liquidity 타이밍 신호)
3. 데이마켓(한국 낮) 이상 급등이 정규장 개장 후 지속되는가, 소멸하는가?
   (블루오션 유동성 공백 위 가격 — 신호 오염원인지 선행 창구인지 판별)
4. 급등 후 덤프의 속도 분포 — 피크에서 -20%까지 걸리는 시간 중앙값, LULD 홀트 개입 빈도
   (스탑·사이징 설계의 근거. 문헌: 크립토는 3.5분 내 붕괴 사례, 미국 소형주는 M사 -85%/1일)
5. 전조 스코어 상위 신호의 기대 수익 분포 (수수료 0.1~0.25%+환전 스프레드+슬리피지 차감 후 양수인가)
6. 시간대 효과 — 개장 15분(밴드 2배, HOD 46.6% 형성)·10:00 ET 전후·마감 전의 신호 성능 차이

## 4. 프로세스 구성

```
collector (단일 프로세스, asyncio)
 ├─ token_manager      — 토큰 단일 발급/갱신 (client당 1토큰 제약)
 ├─ rate_limiter       — 그룹별 토큰버킷 + 429 백오프
 ├─ session_scheduler  — market-calendar 기반 세션 인지 (서머타임 자동 대응)
 ├─ sweep_loops        — tier1_price / tier2_candle / tier3_micro / ranking 루프
 ├─ detector           — 전조 스코어 계산, 티어 승격/강등, 이벤트 감지
 ├─ store              — SQLite 쓰기 (WAL 모드)
 └─ notifier           — 이벤트/승격 알림 (콘솔+로그, 추후 텔레그램)

analyzer (오프라인, 별도 실행)
 └─ 이벤트 라벨링 보정, 전조 피처 추출, 통계 리포트 생성
```

운영: 한국 저녁~새벽(정규장)이 본게임이므로 무인 실행 전제. Windows 작업 스케줄러 또는 상시 실행 + market-calendar로 세션 온오프.

## 5. Phase 2 예고 (감시 결과 확보 후)

- 진입: Phase 1에서 검증된 전조 스코어 + 토스 쏠림도 조건. 초기엔 페이퍼 트레이딩(모니터가 가상 체결 기록)으로 기대값 재검증.
- 청산: 시간 기반 + 트레일링. 덤프 방어는 conditional order `SINGLE`(MARKET, stop-market 상당)을 진입 직후 서버측에 예치. OCO(LIMIT만)는 갭다운 미체결 리스크가 있어 보조 수단.
- 포지션 사이징: **최악 갭(-50~80%, 홀트 재개 갭) 기준으로 ≤1/4 Kelly** (02_theory §5).
  최대손실 목표가 계좌의 1%면 포지션 상한은 계좌의 1.25~2%. 총 동시 노출 상한 별도.
  주문량은 실시간 거래량의 1~5% 이하로 제한 — 슬리피지와 §9(a)(2) 시세관여 이슈 동시 회피.
- 청산 규칙 후보: VWAP 상실 무조건 청산, First Red Day 이월 금지, 어텐션 피크(토스 쏠림도
  정점) = 청산 카운트다운, 오버나이트는 희석 파일링 클린 종목만.
- 절대 금지: 자전거래성 매매, 허수 주문, 커뮤니티 선동 등 시세조종 행위. 우리는 공개 신호에 대한 순수 테이커. 리딩방 매수 지시 동조 매매도 공모 리스크로 금지.
