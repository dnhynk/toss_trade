## 1. 전략 가설 (무엇을 노리는가)

원 아이디어: 넓은 범위의 동전주·예상 작전주·former runner를 감시하다가, 수상한 유동성
공급이 보이는 종목을 2차 선별해 집중 감시하고, **개인들이 커뮤니티·급상승 리스트를 보고
뒤늦게 유동성을 공급할 때 그 유동성을 먹는다.** 덤프에 계좌가 녹지 않도록 보수적으로.

### 조사가 이 가설을 어떻게 정교화했는가 (`docs/02_theory_background.md`)

1. **가설의 메커니즘은 학술적으로 실증돼 있다.** Barber et al. (2022, *Journal of Finance*)
   로빈후드 연구: 앱의 Top Mover 리스트가 **인과적으로** herding을 만들고, herding된 종목은
   이후 20일간 평균 **-4.7%** 비정상수익률. 토스 급상승 리스트는 같은 기계다.
   → **어텐션 피크는 매수 신호가 아니라 청산 카운트다운이다.**
2. **"조용한 매집을 미리 찾는다"는 접근에는 한계가 있다.** La Morgia et al. (2020): 104건 중
   4건에서만 사전 매집이 관찰됐고, 정보 대부분은 **시작 직후 수 초의 체결 버스트**(rush order)에
   있었다. 우리 합성데이터 실험도 재현했다 — 즉발형(instant)은 T0 이전 RVOL이 1.2(완전 정상)라
   **원리상 전조 탐지가 불가능**하다. → 검출기를 **전조 경로 + 확인 경로 2개**로 나눈 이유.
3. **미국판 '주포 덤프'는 희석(dilution)이다.** 고점 오퍼링(424B5), 공지 없는 ATM 드립 매도,
   toxic 워런트. 그리고 **하방 LULD 홀트 중에는 손절 주문이 체결되지 않는다.** 미국은 하한가가
   없어 하루 -85%도 난다(금감원 경보 'M사' 사례).
4. **기저율이 보수적 운영을 강제한다** (SmallCapLab, 900+ 거래일): 프리마켓 대량거래 갭퍼의
   **71.5%가 페이드**, 고점의 **63%가 10:00 ET(≈한국 자정) 전 형성**, **73%가 VWAP 아래 마감**.
5. **비용**: 토스 US 수수료 0.1%/체결(2026 상시 확정) → 왕복 0.2% + 환전 스프레드 + 슬리피지.
   **양도세 22%(연 250만원 초과분), 손실 이월공제 없음** — 이긴 해 과세/진 해 이월 불가의 비대칭.
   → 신호는 조밀하게, **거래는 고확신 이벤트로 압축**해야 복리가 산다.

## 2. 토스 Open API 실측 사실 (가장 중요한 절)

문서에 없거나 문서와 다른 것을 **라이브 호출로 확인한 것**만 적는다.
근거·스니펫: `docs/06_live_facts.md`(W1, 53콜), `docs/11_live_rehearsal.md`(W5).
스펙 자체: `docs/01_api_analysis.md`.

### 2-1. 구조적 제약

| 항목 | 사실 |
|---|---|
| 프로토콜 | **REST 전용. 웹소켓 없음** → 모든 감시는 폴링 |
| 인증 | OAuth2 client credentials. **client당 유효 토큰 1개** — 재발급 시 기존 토큰 즉시 무효화 |
| IP | 화이트리스트 필수 (미등록 시 403) |
| Rate limit | 그룹별 req/s: MARKET_DATA 10, CHART 5, RANKING 5, STOCK 5, MARKET_INFO 3, AUTH 5 |
| 샌드박스 | 없음 |

> **토큰 1개 제약이 아키텍처를 지배한다.** 두 프로세스가 각자 토큰을 발급하면 서로를 죽인다.
> `TokenManager`가 OS 파일락 + 상태파일로 단일성을 강제하지만, **같은 머신·같은 상태파일 경로**가
> 전제다. 경로가 갈리면 락이 무의미해진다 (`docs/08_runbook.md`에 운영 규율로 명시).

### 2-2. 시세 데이터의 실제 거동 (설계를 바꾼 발견들)

1. **1분봉이 최소 1024일(≈2.8년) 보관된다.** (2048일은 빈 응답)
   → "지금부터 쌓아야 한다"는 전제가 무효. **과거 백필로 즉시 분석 가능.**
   단 소형주는 365일까지만 확인됐고, CRKN처럼 **일봉 이력이 41봉뿐인 종목도 있다.**
2. **미국 `/orderbook`은 최우선 1레벨만 준다** (bids 1, asks 1). depth 파라미터 없음.
   → 호가창 깊이·다단 불균형 지표는 **존재할 수 없다.** 테이프(`/trades`) 중심으로 재설계.
3. **소형주는 체결이 없으면 `/prices.timestamp`가 null이거나 과거에 고정된다.**
   같은 배치에서 AAPL은 실시간(지연 중앙값 12.8초)인데 SNTI·CRKN은 null, BTAI는 74분 고정.
   **`lastPrice`는 계속 온다 — 이 값을 "현재가"로 신뢰하면 안 된다.**
   → 오히려 더 나은 신호를 발견: **`first_print`(null→값 전이)와 `staleness` 급감 =
   "휴면 동전주가 깨어나는 순간"**. Tier 1 승격 트리거 1순위로 승격시켰다.
   ※ CRKN은 **17개월간 1분봉 프린트가 없는데 lastPrice는 온다** — 개월 단위 휴면도 존재한다.
4. **`/trades`는 최대 50건** → 활발한 러너의 테이프는 **전량이 아니라 표본**이다.
   체결 크기 분포는 표본 통계로 해석해야 한다.
5. **`adjusted=true`(수정주가)는 임의 정밀도를 만든다.**
   CRKN 2025-03-05: adjusted `0.10461614`(8자리) vs raw `1.9889`(4자리), 비율 ≈ 19.01.
   → 계약 A4·A5의 원인. 아래 §4 참조.
6. **`TOP_GAINERS`/`TOP_LOSERS`는 realtime 미지원**(400). 실시간 등락률 랭킹은 자체 계산해야 한다.
7. **랭킹 스냅샷은 과거 조회가 불가능하다.** 실시간 수집으로만 얻는다 — **수집하지 않은 시간은
   영구히 사라진다.** (검증 질문 2번이 실시간 수집 기간을 요구하는 이유)

### 2-3. 함정 목록 (하나라도 놓치면 데이터가 조용히 틀어진다)

| # | 함정 | 대응 |

### 3-1. 티어드 감시 구조 (`docs/03_phase1_monitor_design.md`)

```
Tier 0  유니버스 (수천, 일 1회)   외부 심볼 디렉토리 + 랭킹 출현 종목 누적
Tier 1  광역 워치 (~1500)        /prices 배치 200개 스윕 45s
Tier 2  활성 워치 (~300)         /candles 1m 110s
Tier 3  집중 감시 (20)           /trades 4s + /orderbook 16s
랭킹    별도 예산                MARKET/TOSS × AMOUNT/VOLUME 4종, 12s
```

**예산 산식 (반드시 지킬 것)** — 한도 × usage_ratio 0.7:

```
MARKET_DATA (10 × 0.7 = 7.0):
  tier1 1500/200/45s = 0.17 + tier3 20/4s = 5.00 + tier3 20/16s = 1.25  →  6.42  ✅
MARKET_DATA_CHART (5 × 0.7 = 3.5):
  tier2 300/110s = 2.73  →  여유 0.77(22%)   ※ 이 여유는 승격 직후 백필용이다
```

> tier3_max=30이면 9.54로 **예산 초과**. tier2를 90s로 하면 여유가 4.8%뿐이라 백필이
> 겹칠 때마다 가드가 tier2를 줄여 **커버리지가 조용히 무너진다.** 두 값 다 실측으로 정한 것이다.

### 3-2. 검출기의 이중 경로 (핵심 설계)

```
precursor_score(feats)   T0 이전 축적: RVOL 궤적·토스 쏠림도·coil·휴면→각성
                         → 리드타임이 있지만 즉발형은 놓친다
confirm_score(feats)     T0 봉 자체의 폭발: 봉 거래량 z, 5분 수익률, coil 급반전
                         → 리드타임 없지만 "시작 후 수 분 내 확인-진입" 가능
```

- 둘 중 큰 쪽으로 승격하되 **승격 사유에 어느 경로였는지 기록**한다 →
  `promotions` 테이블이 나중에 **두 경로의 리드타임·적중률을 따로 평가**할 수 있다.
  이게 Phase 2 모델 설계의 근거 데이터가 된다.
- 모든 피처는 **버킷/램프로 [0,1] 정규화** 후 가중합. `rvol_curve_5`처럼 분모가 작아
  100배를 넘길 수 있는 값은 절대 스케일로 쓰지 않는다.
- **`coil_score`는 부호가 반직관적**: 양수 = 변동성 수축 진행(전조), **강한 음수 = 방금 폭발 시작**(확인).
- **NaN 피처는 0점.** 데이터가 없을수록 점수가 낮아야 승격이 보수적으로 일어난다.

| C-1 | 모든 시간은 **UTC epoch ms 정수**. KST/ET 변환은 표시 레이어에서만. 세션은 API 캘린더로만 판정 |
| C-2 | 가격·금액 = **마이크로달러 int**, 수량 = 마이크로주 int. **float 금지**(중간 계산 포함) |
| C-5 | 에러별 재시도 책임 위치 고정 (RateLimited/AuthExpired/Transient는 client 내부, SchemaMismatch는 caller 스킵, Forbidden은 치명) |
| C-6 | SQLite WAL, **쓰기는 collector 단일 프로세스**, 분석기는 read-only |
| C-9 | `TOSS_BASE_URL`로 mock 전환. **리스 없는 워커는 mock만** |
| C-11 | **주문/조건주문/계좌변경 금지** — 래퍼조차 만들지 않고 HTTP 레벨 이중 차단 |

### 개정 (전부 실측·실험에서 나왔다)

- **A1 (분석 해석)**: 룩어헤드 컷오프를 **엄격히 `ts_ms < t0_ms`** 로 하되
  **`include_t0` 플래그**를 제공. 이유: 실시간 검출기는 T0 봉 종료 시점에 판정하므로
  T0 봉을 정당하게 볼 수 있다. 플래그가 없으면 W4가 같은 로직을 재구현하게 된다.
  또 **RVOL은 세션 누적 기준**(문헌의 3~5x 임계가 누적 지표라서), `ret_30m`은 진입 기준으로
  고정하고 되돌림은 `retrace_*`로 분리. **RVOL 게이트 미적용 이벤트는 통계에서 분리**해야 한다
  (조용한 오염 방지).
- **A2 (라이브 실측 반영)**: 호가 1레벨 확정 → 테이프 중심 재배분. 소형주 timestamp null →
  **`first_print`를 Tier 1 승격 1순위**로. 1분봉 1024일 보관 → **백필 분석(1-A)과
  실시간 수집(1-B) 병행**으로 계획 변경.
- **A3 (호가 불균형)**: 계약은 비율형 `[0,1]`, 코드는 부호형 `[-1,1]`이었다. 중립점이 달라
  (0.5 vs 0) 소비자가 조용히 틀린다. **부호형을 정본으로 하고 컬럼명을 `imbalance_signed`로
  변경** — 이름이 규약을 말하게 했다. 수집 시작 전이라 마이그레이션 없이 가능했다.
- **A4 (정밀도)** ★: `dec_to_u`가 1e-6 초과 정밀도를 `SchemaMismatch`로 거부 → C-5에 따라
  **심볼 스킵**. 그런데 스킵되는 게 하필 **표적 종목군(저가 동전주)** 이었다.
  → **반올림(ROUND_HALF_EVEN)으로 변경 + 반올림 카운터 노출.**
  나노달러로 바꾸지 않은 이유: 가격×수량 누적이 int64를 1000배 빨리 넘긴다.
  실측: 라이브에서 **17,179건 중 13건 반올림 발생** — 예전 코드였다면 13건이 전부 스킵됐다.
- **A5 (수정주가)** ★: 수정주가는 **그 시점의 명목 가격을 지운다**. CRKN은 실제로 $1.99에
  거래됐는데 수정주가로는 $0.10로 보인다 → **당시 $2 종목을 동전주로 오분류**한다.
  게다가 sub-penny 호가·LULD 밴드 경계($0.75/$3)가 전부 명목가 기준이다.
  → **1분봉은 원주가(`adjusted=false`), 일봉은 수정주가(`adjusted=true`).**
  분할은 장중에 없으므로 일중 상대 변화는 원주가로도 동일 — 잃는 게 없다.

| 코디 | **`events` 중복 기록** — 검출기가 매 사이클 재검출하는데 유니크 제약이 없어 라이브 17분에 26행/고유 10개 | q1~q6 통계가 조용히 부풀려진다. UNIQUE + **UPSERT**(IGNORE 아님 — T0 시점 라벨은 미완성) |

| W5 | healthcheck가 사건성 테이블(events/promotions)을 상시 폴링 테이블과 같은 staleness 게이트로 판정 → **오탐 CRIT** | 오탐 경보는 "경보 무시 습관"을 만들어 진짜 경보를 묻는다 |
| W5 | **에이전트 세션의 백그라운드 잡으로 띄운 collector가 세션 정리 시 함께 종료** (3개 동시 사망) | **감시 대상을 감시자의 자식 프로세스로 두지 마라.** 무인 운영은 작업 스케줄러 등록 또는 `Start-Process` 분리 프로세스로만 |
| 코디 | **브랜치 간 통합 실패** — W4 브랜치는 단독 625 passed였으나 W2의 UNIQUE+UPSERT와 합치자 `rows == new + updates` 불변식이 깨짐 | 각 브랜치가 옳아도 조합은 틀릴 수 있다. **머지 후 통합 스모크(게이트 5)가 유일한 방어선.** 후속 태스크는 rebase 먼저 |

**공통 패턴**: 이 프로젝트에서 가장 비싼 실패는 전부 **"조용히 틀리는" 것**이었다.
예외를 던지고 죽는 코드는 금방 고친다. 값이 조금씩 틀린 채 흘러가는 코드는 몇 주 뒤에
데이터를 다 버리게 만든다. **규약은 이름에 새기고, 테스트로 고정하고, 관측 가능하게 하라.**

## 8. Phase 2(실매매) 착수 전 반드시 할 것

### 8-1. 아직 답하지 않은 질문 (Phase 1의 존재 이유)

`docs/03` §3의 검증 질문 6개에 **수치로 답이 나오기 전에는 실매매 로직을 짜지 마라.**

1. 거래량 이상은 가격 급등보다 몇 분 선행하는가? 임계값별 정밀도/재현율은?
2. **토스 랭킹 진입은 가격 대비 선행인가 후행인가?** ← 사용자 엣지 가설의 핵심.
   후행이면 랭킹은 진입 신호가 아니라 **청산 유동성 타이밍 신호**다.
3. 데이마켓 급등이 정규장에서 지속되는가, 소멸하는가?
4. 피크→-20% 소요 시간 분포와 홀트 개입 빈도 (스탑·사이징의 근거)
5. 전조 스코어 조건부 기대수익이 **비용 차감 후 양수인가**
6. 시간대 효과 (개장 15분 / 10:00 ET 전후 / 마감 전)

### 8-2. 미완·미검증 항목

- **W6 적대적 감사 미실행.** 토큰 단일성 파괴 경로, rate limit 초과 경로, 룩어헤드,
  세션 경계 버그, 시크릿 유출, 크래시 후 무결성, GET-only 우회 가능성을
  **반증하려는 태도로** 감사해야 한다. Phase 2 착수 전 필수.
- **일봉 이력이 짧은 종목**(CRKN 41봉)은 20일 베이스라인을 만들 수 없다.
  유니버스 필터에 최소 이력 조건이 필요한지, 아니면 짧은 이력용 대체 베이스라인이
  필요한지 미결. 신규 상장 소형주가 러너가 되는 경우가 많아 단순 배제는 표적을 놓친다.
- **개월 단위 휴면 종목**(CRKN 17개월 무프린트) 처리 방침 미정.
- 극단적 리버스 스플릿 누적 시 일봉 수정주가가 1e-6 미만으로 뭉개질 가능성
  (3종목 표본에서는 미관측, **"불가능함이 증명된 것은 아니다"**).

### 8-3. 실매매 설계 시 지켜야 할 것

- **포지션 사이징은 손절가가 아니라 최악 갭 기준으로.** 하방 LULD 홀트 중에는 주문이
  체결되지 않고 재개 시 5~10%+ 갭이 난다. 최대손실 1% 목표면 포지션은 계좌의 1.25~2% 상한.
  **≤1/4 Kelly** (풀켈리는 자본이 X%까지 갈 확률이 X%).
- **주문가에 반올림값을 쓰지 마라.** A4의 반올림은 표시·분석용이다. 주문가가 필요하면
  응답 원문 문자열을 별도 보존해야 한다.
- **주문량은 실시간 거래량의 1~5% 이하로 제한.** 초저유동성 종목에서 본인 주문이
  가격을 미는 반복 패턴은 §9(a)(2) 시세관여로 재구성될 수 있다.
- **덤프 방어**: 조건주문 `SINGLE`(MARKET)이 stop-market 상당으로 서버측에 예치 가능.
  OCO는 지정가만이라 갭다운 미체결 리스크가 있다.
- **어텐션 피크 = 청산 카운트다운** (Barber 2022). VWAP 상실·First Red Day는 무조건 청산.
- **절대 금지**: 자전거래성 매매, 허수 주문, 커뮤니티 선동, 리딩방 지시 동조.
  우리는 공개 신호에 대한 순수 테이커다.
